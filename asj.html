1. Pengantar ASJ Kelas 12

Di kelas 12, fokus pembelajaran tidak lagi sebatas menginstal server berdiri sendiri (seperti Web, DNS, Mail, FTP, DHCP di kelas 11)[cite: 2], melainkan mengintegrasikan berbagai layanan jaringan[cite: 2], memonitor ketersediaan sistem[cite: 2], dan mengamankannya secara menyeluruh[cite: 1, 2].

Shared Hosting, VPS, dan Dedicated Server

Shared Hosting

Beberapa pengguna menyewa dan berbagi satu server fisik yang sama beserta seluruh resource-nya (CPU, RAM, Storage)[cite: 2].
Contoh: smkn1batam.sch.id[cite: 2]

VPS (Virtual Private Server)

Komputer virtual di atas server fisik yang diisolasi, memiliki OS sendiri, dan dapat diakses jarak jauh melalui internet[cite: 2].
Contoh: belajar.dikelasawan.my.id[cite: 2]

Dedicated Server

Pengguna menyewa satu komputer fisik utuh secara eksklusif tanpa berbagi sumber daya dengan pengguna lain[cite: 2]. Cocok untuk trafik berskala tinggi.

Control Panel Hosting & Teknologi VPN

Control Panel Hosting

Aplikasi berbasis GUI yang mempermudah pengelolaan layanan server (Web, Mail, Database, FTP, Domain) tanpa perlu mengetik perintah CLI manual[cite: 2].

cPanel Plesk Webmin VistaPanel[cite: 2]

Virtual Private Network (VPN)

  • • Remote Client VPN: Menghubungkan client/staf WFH langsung ke jaringan LAN kantor[cite: 2].
  • • Site-to-Site VPN: Menghubungkan dua jaringan lokal kantor yang terpisah geografis[cite: 2].
  • • Protokol PPTP: Menggunakan autentikasi User & Password[cite: 2].
  • • Protokol OpenVPN: Menggunakan SSL/TLS & Sertifikat digital untuk keamanan ekstra[cite: 2].

Control Monitoring Server & Keamanan Sistem

Keamanan Fisik vs Non-Fisik

  • • Fisik: CCTV, APAR, Alarm, Kabel trunking, Grounding, Fingerprint server[cite: 1, 2].
  • • Non-Fisik: Rule Firewall, Subnetting, Hak akses user, Enkripsi data[cite: 1, 2].
  • ⚡ Prinsip: "NO SYSTEM IS SAFE" — Keamanan harus berlapis[cite: 1, 2].

Manfaat Control Monitoring

  • • Efisiensi SDM: Memantau status router, switch, & server secara terpusat[cite: 2].
  • • Visibilitas Real-time: Mengetahui kondisi traffic dan penggunaan resource[cite: 2].
  • • Otomatisasi Alert: Mengirim notifikasi otomatis ke WhatsApp/Telegram saatdown[cite: 2].

Panduan Lengkap Perintah CLI Praktikum

Perangkat Perintah CLI / File Konfigurasi Fungsi / Penjelasan Ringkas
MikroTik interface print Melihat daftar seluruh interface ethernet router[cite: 1].
MikroTik ip address add address=... interface=... Menambahkan IP address baru pada interface spesifik[cite: 1].
MikroTik ip route add dst-address=0.0.0.0/0 gateway=... Menentukan jalur Default Gateway ke internet[cite: 1].
MikroTik ip dns set servers=... allow-remote-request=yes Mengonfigurasi DNS server dan DNS forwarder[cite: 1].
MikroTik ip firewall nat add action=masquerade chain=srcnat... Mengaktifkan NAT agar jaringan lokal dapat terhubung internet[cite: 1].
Debian 8 nano /etc/network/interfaces Mengatur konfigurasi IP Address static/DHCP Debian[cite: 1].
Debian 8 /etc/init.d/networking restart Merestart seluruh konfigurasi jaringan Debian[cite: 1].
Debian 8 traceroute 1.1.1.1 Mengecek hop/rute lintasan paket gateway[cite: 1].
