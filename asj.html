1. Pengantar ASJ Kelas 12

Di kelas 12, fokus utama pembelajaran bukan lagi sekadar menginstal server berdiri sendiri (seperti Web, DNS, Mail, FTP, dan DHCP di kelas 11), melainkan mengintegrasikan berbagai layanan jaringan, memonitor ketersediaan sistem secara terpusat, dan mengamankan infrastruktur jaringan secara komprehensif.

Shared Hosting, VPS, dan Dedicated Server

Shared Hosting

Beberapa pengguna menyewa dan berbagi sumber daya pada satu server fisik yang sama (CPU, RAM, Storage).

Contoh: smkn1batam.sch.id

VPS (Virtual Private Server)

Server virtual yang berjalan di atas server fisik, diisolasi dengan OS sendiri, dan dapat diakses dari mana saja melalui internet.

Contoh: belajar.dikelasawan.my.id

Dedicated Server

Satu komputer server fisik disewa secara eksklusif oleh satu pengguna tanpa berbagi resource dengan pihak lain. Sangat cocok untuk trafik berskala besar.

Control Panel Hosting & Teknologi VPN

Control Panel Hosting

Aplikasi berbasis web (GUI) yang mempermudah admin dalam mengelola dan mengonfigurasi layanan server (Web Server, Database, FTP, Mail) tanpa perlu mengetikkan perintah CLI manual.

cPanel Plesk Webmin VistaPanel / EHCP

Virtual Private Network (VPN)

Jaringan privat aman yang dibangun di atas publik (Internet):

  • • Remote Client VPN: Menghubungkan perangkat pegawai/WFH langsung ke LAN kantor.
  • • Site-to-Site VPN: Menghubungkan 2 jaringan LAN kantor yang berbeda lokasi fisik.
  • • PPTP: Menggunakan otentikasi sederhana User & Password.
  • • OpenVPN: Menggunakan SSL/TLS & Sertifikat digital untuk enkripsi tingkat tinggi.

Control Monitoring Server & Keamanan Sistem

Keamanan Fisik vs Non-Fisik

  • • Keamanan Fisik: CCTV, APAR/Pemadam Api, Alarm, Trunking Kabel, Grounding, Fingerprint Server.
  • • Keamanan Non-Fisik: Firewall Rules, Subnetting, Hak Akses/Pelevelan User, Enkripsi Data.
  • ⚡ Prinsip Keamanan: "NO SYSTEM IS SAFE" — Tidak ada sistem yang aman 100%.

Sistem Control Monitoring Server

Memantau status router, switch, server, dan service terpusat:

  • • Efisiensi SDM: Tidak perlu mengecek setiap server satu per satu.
  • • Visibilitas Real-time: Mengetahui beban CPU, RAM, & trafik jaringan.
  • • Otomatisasi Alert: Mengirim notifikasi otomatis via WA/Telegram jika ada server down.

Rincian Perintah CLI & File Konfigurasi Praktikum

Perangkat Perintah CLI / File Konfigurasi Fungsi / Penjelasan Ringkas
MikroTik RouterOS interface print Menampilkan daftar seluruh interface jaringan pada router.
MikroTik RouterOS ip address add address=... interface=... Menambahkan konfigurasi IP Address pada interface spesifik.
MikroTik RouterOS ip route add dst-address=0.0.0.0/0 gateway=... Menentukan rute default gateway menuju jaringan internet.
MikroTik RouterOS ip dns set servers=... allow-remote-request=yes Mengatur IP DNS Server dan mengaktifkan DNS forwarder.
MikroTik RouterOS ip firewall nat add action=masquerade chain=srcnat... Mengaktifkan NAT Masquerade agar jaringan lokal dapat terkoneksi ke internet.
Debian 8 Linux nano /etc/network/interfaces Mengedit konfigurasi IP Address static maupun DHCP server Debian.
Debian 8 Linux /etc/init.d/networking restart Merestart seluruh service adapter jaringan pada Debian.
Debian 8 Linux traceroute 1.1.1.1 Menguji dan melacak rute lintasan paket gateway menuju IP tujuan.
Debian 8 Linux nano /etc/apt/sources.list Mendaftarkan repository server untuk instalasi paket aplikasi.
Debian 8 Linux apt-get install apache2 mysql-server php5 phpmyadmin Menginstal stack Web Server, Database MySQL, & phpMyAdmin.
