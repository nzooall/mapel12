🌍 3. Modul 2 — Konfigurasi Internet (ether3) & Routing Default (modul2.html)

Langkah menghubungkan router ke ISP via interface WAN (ether3) secara dinamis agar terhubung ke internet.

  • DHCP Client (WAN): Navigasi ke IP → DHCP Client → Tambah (+) → Interface: ether3 | Use Peer DNS: ✓ | Add Default Route: ✓.
  • Verifikasi Routing: Navigasi ke IP → Routes → Pastikan rute tujuannya 0.0.0.0/0 aktif (Flags: AS/ADC).
  • NAT Masquerade: Navigasi ke IP → Firewall → NAT → Tambah (+):
    • Tab General: Chain: srcnat | Out. Interface: ether3
    • Tab Action: Action: masquerade

📶 4. Modul 3 — Konfigurasi IP LAN, DHCP Server & Hotspot (modul3.html)

Pengelolaan alokasi IP lokal (ether4), distribusi IP otomatis, Captive Portal Hotspot, dan limitasi kecepatan (bandwidth).

  • IP LAN (ether4): IP → Addresses → Address: 172.32.xx.1/24 | Interface: ether4 (xx = No. Absen).
  • IP Pool LAN: IP → Pool → Name: dhcp-pool-lan | Addresses: 172.32.xx.21-172.32.xx.70.
  • DHCP Setup: IP → DHCP Server → DHCP Setup → Interface: ether4 | Range: 172.32.xx.21-172.32.xx.70.
  • Hotspot Setup: IP → Hotspot → Hotspot Setup → Interface: ether4 | DNS Name: wifi-namasiswa.com.
  • User Profiles (Rate Limit): IP → Hotspot → User Profiles:
    • profile-guru: Rate Limit = 10M/10M
    • profile-siswa: Rate Limit = 5M/5M
  • Users Hotspot: IP → Hotspot → Users → Tambahkan akun guru dan siswa sesuai profilnya.

🛡️ 5. Modul 4 — Firewall Filter Rules & Pemblokiran File (modul4.html)

Keamanan jaringan melalui aturan filter ICMP (Ping) serta 3 pilihan metode pemblokiran unduhan file `.mp3`.

  • Blokir Ping Pool ke Router: IP → Firewall → Filter Rules → Chain: input | Src. Address: 172.32.xx.21-172.32.xx.70 | Protocol: icmp | Action: drop.
  • Blokir Ping Antar Klien (21-30 ke 61-70): IP → Firewall → Filter Rules → Chain: forward | Src. Address: 172.32.xx.21-172.32.xx.30 | Dst. Address: 172.32.xx.61-172.32.xx.70 | Protocol: icmp | Action: drop.
  • Pemblokiran File .mp3 (Metode 1: Layer7 Protocol - Utama):
    • IP → Firewall → Layer7 Protocols → Name: block-mp3 | Regexp: ^.*\.mp3.*$
    • IP → Firewall → Filter Rules → Chain: forward | Src. Address: 172.32.xx.0/24 | Protocol: tcp | Layer7 Protocol: block-mp3 | Action: drop
  • Pemblokiran File .mp3 (Metode 2: Firewall Content - Alternatif 1):
    • IP → Firewall → Filter Rules → Chain: forward | Protocol: tcp | Dst. Port: 80 | Src. Address: 172.32.xx.0/24 | Content: .mp3 | Action: drop
  • Pemblokiran File .mp3 (Metode 3: Web Proxy Access - Alternatif 2):
    • IP → Web Proxy → Enabled: ✓ | Port: 8080 | Anonymous: ✓
    • Web Proxy Access → Path: *.mp3 | Action: deny
    • IP → Firewall → NAT → Chain: dstnat | Protocol: tcp | Dst. Port: 80 | In. Interface: ether4 | Action: redirect | To Ports: 8080
